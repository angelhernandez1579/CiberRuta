# 🛡️ CiberRuta

Aplicación web interactiva tipo Duolingo para aprender seguridad digital y ciberseguridad.

## Características
- 6 unidades: contraseñas, phishing, redes, malware, privacidad e ingeniería social.
- Teoría antes de cada lección y preguntas con explicación.
- Corazones, XP, racha diaria y progreso guardado en el navegador.
- Animaciones y sonidos generados con Web Audio (sin archivos externos).

## Cómo usarla
Abre `index.html` en cualquier navegador moderno. No requiere instalación.

## Agregar contenido
Edita el arreglo `U` dentro de `index.html`. Cada lección tiene `t` (título), `th` (teoría) y `q` (preguntas en formato `[pregunta, opciones, índice_correcto, explicación]`).
